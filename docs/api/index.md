# API Reference

These pages document modules, classes, functions, and generated API details.
They are most useful when you already know which package or import path you
need.

If you are choosing between packages, start with [Packages](../packages/index.md).
If you are learning how the pieces fit together, start with
[Simulation & Analysis](../packages/simulation-analysis.md) or the package
overview pages.

## API Groups

| Group | Contents |
|---|---|
| Framework API | `gds` core specification, type, state, compiler, canonical, and verification modules |
| Domain APIs | `gds_domains.*` DSL modules for games, business, stock-flow, control, and software |
| Interchange and Visualization APIs | `gds_viz` and `gds_interchange.owl` modules |
| Simulation APIs | `gds_sim` runtime modules |
| Analysis APIs | `gds_analysis.psuu` parameter search, objective, optimizer, and sensitivity modules |

The API pages intentionally stay factual and compact. For task-oriented usage,
use the package guides and how-to pages.
